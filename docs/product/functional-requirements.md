## 规范

- `Must` 是 v0.1 发布必需；`Should` 可在不破坏主流程时延后，但必须显式过门禁。
- 每项需求是稳定事实源；验收时必须保存测试或人工证据。
- “应用”指 CyberMuse 桌面端，“analyzer”指本地 Python sidecar。

## 歌曲与分析

### FR-001 — 导入支持格式

- 优先级：Must
- 前置条件：用户位于 Library 或 Import，文件选择器可用。
- 行为：应用允许选择单个 `.mp3`、`.wav` 或 `.flac` 文件，并在用户确认后开始导入。
- 异常：取消选择不创建记录、不显示错误。
- 验收：三种支持格式分别可进入校验状态；其他扩展名不可选择或被明确拒绝。

### FR-002 — 校验音频

- 优先级：Must
- 前置条件：已选择输入文件。
- 行为：应用探测容器、音频流、时长、可解码性和剩余磁盘空间，再创建正式歌曲资产。
- 异常：损坏、无音轨、零时长、无法读取或空间不足时，展示原因和恢复动作。
- 验收：每类无效输入均不产生可练习歌曲，不覆盖现有数据。

### FR-003 — 建立本地歌曲资产

- 优先级：Must
- 前置条件：FR-002 通过。
- 行为：应用以输入内容 SHA-256 派生 `songId`，复制原始文件到应用本地数据目录，并原子写入歌曲元数据。
- 异常：复制中断时清理临时文件；同内容重复导入复用同一歌曲记录并提示用户。
- 验收：移动或删除原始外部文件后，已导入歌曲仍可使用；同一内容不会重复占用完整资产空间。

### FR-004 — 控制分析任务

- 优先级：Must
- 前置条件：歌曲资产有效，所需模型可用。
- 行为：用户可启动、观察分阶段进度、取消、失败后重试分析；同一歌曲同一时间最多一个活动任务。
- 异常：sidecar 异常退出、取消、磁盘不足和模型不可用都转为结构化终态。
- 验收：进度阶段顺序正确；取消在 NFR 时限内生效；重试不破坏最后一次有效结果。

### FR-005 — 生成练习资产

- 优先级：Must
- 前置条件：FR-004 成功运行。
- 行为：analyzer 生成 `instrumental.wav`、`vocals.wav` 和带连续 F0 的 `analysis.json`。
- 异常：任何必需产物缺失、哈希不符或 schema 无效时，任务不得标记完成。
- 验收：完成事件只在 manifest 和全部必需产物原子可见后产生。

### FR-006 — 复用版本兼容的缓存

- 优先级：Must
- 前置条件：歌曲已存在分析结果。
- 行为：输入哈希、配置、模型版本和 schema 兼容时复用缓存；任一关键指纹变化时创建新分析版本。
- 异常：旧版本仍可保留用于回退，但不可冒充当前结果。
- 验收：重复分析不启动模型；改变模型版本触发新任务并保留旧结果直到新结果成功。

### FR-007 — 管理歌曲库

- 优先级：Must
- 前置条件：应用已启动。
- 行为：Library 显示歌曲标题、导入时间、时长、分析状态和最近练习时间，并可打开、重试分析或删除。
- 异常：资产缺失显示可修复状态，不导致整个 Library 无法打开。
- 验收：空库、处理中、可练习、失败和损坏状态均有确定显示和操作。

### FR-008 — 删除歌曲数据

- 优先级：Must
- 前置条件：用户选择删除一首歌曲。
- 行为：应用在确认后删除该歌曲副本、派生产物和练习记录；活动分析先取消。
- 异常：部分删除失败时报告残留位置并允许重试，不把残留标记为已清除。
- 验收：删除成功后 Library、磁盘资产和会话索引均无该 `songId`。

## 播放与实时练习

### FR-009 — 播放控制

- 优先级：Must
- 前置条件：歌曲有有效伴奏和参考轨。
- 行为：用户可播放、暂停、从任意有效时间 seek、回到开头；位置由播放主时钟驱动。
- 异常：seek 超界被夹取到有效范围；资源不可读时停止并提示恢复动作。
- 验收：每种控制后 UI、参考轨和声音位置一致，符合 NFR-004。

### FR-010 — 麦克风授权和设备选择

- 优先级：Must
- 前置条件：进入 Audio Settings 或 Practice。
- 行为：应用在解释用途后请求麦克风权限，列出可用输入设备，允许选择并显示输入电平。
- 异常：拒绝、设备消失、被占用或静音时，播放仍可用，但练习评分不可开始并显示恢复方法。
- 验收：授权、拒绝、切换和拔出设备四条路径均不崩溃且状态可恢复。

### FR-011 — 实时检测用户音高

- 优先级：Must
- 前置条件：麦克风可用且练习已开始。
- 行为：Worker 输出时间戳、`hz`、`midi`、`confidence`、`voiced` 和 RMS；低置信度或低电平帧不参与评分。
- 异常：非有限值、超支持范围和中断输入转为无声或受控错误，不进入持久化数据。
- 验收：合成音、静音、噪声和断开设备的输出符合 Data Model 与测试容限。

### FR-012 — 显示参考与用户音高

- 优先级：Must
- 前置条件：Practice 已加载参考轨。
- 行为：界面固定 NOW 位置，时间轴向左移动，显示过去用户轨和未来参考轨；颜色之外还用垂直位置和文字表达偏差。
- 异常：无有效用户帧时显示“未检测到稳定音高”，不绘制 `0 Hz`。
- 验收：播放、暂停、seek、loop 和窗口缩放后图形与主时钟一致。

### FR-013 — 显示即时偏差反馈

- 优先级：Must
- 前置条件：当前参考和用户帧均有效。
- 行为：应用计算有符号 cents 差；Pitch Lane 下方的独立反馈舞台以大字号显示稳定后的教练提示，并以辅信息保留目标音名、当前音名和 signed cents。麦克风 ready 后，图例旁的状态固定为绿色圆点与“正在录唱”，不得被方向或数值替换。反馈舞台首个有效结果立即出现，之后最多每 300 ms 原子替换一次提示与辅信息。
- 异常：参考或用户无声时不产生准确/失败评价。短暂无声保留最近有效反馈最多 600 ms，之后显示“等待稳定音高”；无参考音、暂停、结束、seek、loop 边界、歌曲或设备变化、麦克风退出 ready 和评分模式切换必须立即作废跨边界旧反馈。
- 验收：已知频率比产生预期 cents；边界值按评分规范稳定分类；受控时钟证明首条立即显示、20 ms 原始观察不会逐条改字、300 ms 采用最新完整反馈、600 ms 无声保持后转为中性，且呈现节流不改变评分、take、metrics 或 session。

### FR-014 — A-B 区间循环

- 优先级：Must
- 前置条件：歌曲已加载。
- 行为：用户可设置、调整、启用和清除满足最短长度的 `[startMs, endMs)` 区间；播放到 B 后回到 A，并开始新 take。
- 异常：A/B 超界、顺序错误或区间过短时拒绝并解释原因。
- 验收：连续十次循环边界与参考轨符合 NFR-004，take 数据不跨循环混合。

### FR-015 — 麦克风延迟校准

- 优先级：Must
- 前置条件：输入与输出设备可用，环境允许播放校准信号。
- 行为：应用引导用户完成回环测量，保存设备组合对应的输入补偿 `latencyMs`，并允许手动重测或清除。
- 异常：信号不足、多峰歧义或设备变化时不保存无效结果。
- 验收：有效校准被应用到评分时间；切换任一设备后要求重新确认对应补偿。

## 评分、记录与设置

### FR-016 — 计算练习指标

- 优先级：Must
- 前置条件：至少存在一个有效匹配帧。
- 行为：按一次 take 和整个 session 计算 `pitchAccuracy`、`medianAbsoluteErrorCents`、`signedMedianErrorCents`、`stability`、`coverage`。
- 异常：样本不足的指标标记为不可用，不伪造 0 分。
- 验收：固定输入序列得到确定结果；整体偏低但稳定与均值接近零但波动大的序列得到不同诊断。

### FR-017 — 保存练习会话

- 优先级：Must
- 前置条件：用户开始 Practice。
- 行为：结束或离开时保存 session 元数据、有效音高观察、loop/take 边界、指标、分析版本和设备校准引用；再次进入同一分析版本的 Practice 时恢复最近已保存且含有效帧的 take 作为“上次录唱”，部分歌曲区间同样有效，之后的空伴奏预览不得覆盖它。
- 异常：写入失败不阻止用户离开，但明确提示未保存并允许重试导出诊断；历史 take 读取失败不得阻断新的 Practice。
- 验收：重新启动应用后可打开已保存会话，并可在 Practice 看到最近一次有效的完整或部分 take；自然播放结束会封口 take，空 take 不会遮蔽最近有效 take；数据符合 schema 且引用存在。

### FR-018 — Review 练习结果

- 优先级：Must
- 前置条件：存在已完成或可部分回顾的 session。
- 行为：Review 显示整体指标、时间线错误分布、偏高/偏低摘要和可回到 Practice 的区间。
- 异常：部分音高数据损坏时展示仍可用摘要并标出不可用范围。
- 验收：用户能从错误区间创建新的 A-B loop，不需要重新查找时间点。

### FR-019 — 管理模型资产

- 优先级：Must
- 前置条件：分析需要尚未安装的经批准模型。
- 行为：应用显示模型名称、用途、大小、来源和许可证，获同意后下载、校验 SHA-256、原子安装，并允许删除缓存。
- 异常：离线、取消、空间不足或哈希失败时不得留下可被加载的部分模型。
- 验收：未同意不联网；哈希不符拒绝安装；删除后下次分析重新进入同意流程。

### FR-020 — 保存本地设置

- 优先级：Must
- 前置条件：用户修改受支持设置。
- 行为：保存输入/输出设备稳定标识、音量、校准、主题、动效、语言偏好和模型缓存选择，不保存敏感音频内容。Practice 自动恢复/更新设备身份与 Settings 用户操作必须经过同一个进程内 revision 队列，不得各自持有可并发写入的 revision 副本。
- 异常：设备标识失效时回退系统默认并提示，不阻止应用启动。
- 验收：重启后有效设置恢复；无效设备回退可见且可更正；Practice 保存设备身份后立即切换主题/动效/语言时使用最新 revision，不产生伪冲突或要求恢复默认设置。

### FR-021 — 导出诊断包

- 优先级：Should
- 前置条件：出现可诊断问题或用户从设置主动选择。
- 行为：生成不含音频、完整原路径和个人内容的本地诊断包，列出版本、设备能力、错误码、性能摘要和脱敏日志。
- 异常：用户必须预览包含项并选择保存位置；取消不产生文件。
- 验收：自动扫描诊断包不含受禁字段，包可用于复现环境问题。

### FR-022 — 切换界面语言

- 优先级：Must
- 前置条件：应用启动或用户在设置中选择语言。
- 行为：应用支持跟随 Windows、简体中文和 English；切换立即更新全部用户可见文案、辅助功能文本及本地格式，无需重启。
- 异常：旧设置缺少语言字段时按“跟随 Windows”处理；设置保存失败时恢复最后一次有效偏好并显示可恢复错误。
- 验收：中文和英文模式均无另一语言的界面文案混入，品牌名、标准单位、产品/技术专名和稳定错误码除外；重启后选择恢复。

### FR-023 — 管理应用存储

- 优先级：Must
- 前置条件：用户打开设置中的存储管理。
- 行为：应用按歌曲资产、模型、诊断日志、临时数据和其他设置数据显示本机占用，并提供进入歌曲/模型单项删除流程及清除诊断日志的动作。
- 异常：统计不得跟随链接或扫描应用目录外路径；统计失败不影响 Library、Practice 或已有数据，临时数据不得在活动任务期间手动删除。
- 验收：分类字节数和项目数可复现；页面不接收完整路径；歌曲、模型和日志清理继续使用明确确认并在完成后刷新统计。

## 歌词

### FR-024 — 管理用户提供的歌词

- 优先级：Must（v0.2 M7）
- 前置条件：歌曲已经导入，用户位于 Library。
- 行为：用户可为单曲选择一个本地 `.lrc` 文件，在预览后确认添加或替换，并可经明确确认移除；应用保存歌词内容的本地副本，不依赖原文件继续存在。
- 异常：取消选择不产生状态；解析、替换或删除失败时保留最后一次有效歌词并显示结构化恢复动作。
- 验收：添加后重启和原文件移走仍可使用；相同文件复用；替换中断不破坏旧版本；移除和删除歌曲会清除应用管理的歌词副本。

### FR-025 — 解析并校准 LRC

- 优先级：Must（v0.2 M7）
- 前置条件：用户选择了大小和编码受支持的 LRC。
- 行为：应用在 Rust 中解析 UTF-8 或带 BOM 的 UTF-16 LE/BE 行级时间标签、常见元数据和文件 `offset`，展开多时间戳行，并把同一时间戳的多行合并为一个 cue group。用户可在 Practice 中以 100 ms 步长或数值输入保存整份歌词的 `userOffsetMs`。
- 异常：无有效时间行、非法编码/数值、冲突 offset、超出资源上限或全部 cue 与歌曲时长无交集时拒绝；Enhanced LRC 只降级到行级文本并明确提示忽略逐词时间。
- 验收：固定 LRC fixture 产生确定的整数 `timeMs` cue；文件 offset 与用户 offset 分开保存；同刻原文/翻译保持源顺序；偏移重启后恢复。

### FR-026 — 显示同步歌词

- 优先级：Must（v0.2 M7）
- 前置条件：歌曲有有效歌词资产并进入 Practice。
- 行为：原有 Practice UI 位于左列，歌词位于右侧由 1 px 分割线划分的独立滚动区；当前 cue 按播放主时钟高亮并自动跟随。用户可滚动查看前后歌词、恢复跟随，并用鼠标或键盘激活某行跳转到其有效时间。
- 异常：歌词缺失或损坏不阻止伴奏、音高轨或评分；没有歌词时保持原有单列布局，不显示空歌词区。
- 验收：播放、暂停、回到开头、seek、点击歌词、A-B loop 和正负偏移后当前行均与 `PlaybackSnapshot.positionMs` 一致；1024×720 与 150% 缩放仍保持右侧歌词列，左侧内容允许收窄和换行。

## 音高训练升级

### FR-027 — 提供稳定、可解释且可切换的音高通道

- 优先级：Must（v0.2 M8）
- 前置条件：歌曲参考轨已经加载并进入 Practice。
- 行为：Pitch Lane 保持 8 秒窗口与 20% NOW；M10 将连续带边界参考通道替换为互不连接的实心校准刻度，每个可见刻度聚合约 80–120 ms 参考音高，以嵌套厚度分别表达精确中心、±25 cents 核心区和 ±50 cents 可接受区，不绘制连续外框、虚线边界或连接相邻刻度。乐句由至少 1,000 ms 无声间隔划分，乐句内纵轴固定为整数 MIDI、上下各留 2 个半音且最少覆盖 16 个半音，并显示半音网格、强化 C/八度线、音名、降采样包络、极值和越界标记。Practice 的“练习数据”右侧提供默认开启、只在当前页面生命周期内有效的“专业模式 开/关”原生 switch。
- 模式语义：专业模式使用检测音高与目标音高的绝对 signed cents；关闭后为每个有参考的观察选择整数八度偏移，使绝对 cents 最小，±600 cents 平局保留原方向。曲线、当前音名、cents、反馈等级、take 和 session 指标使用同一结果；原始检测 MIDI 与 `absoluteSignedCents` 始终保留。无参考帧不评分、不折叠、不借用过期目标，以“未评分”线型显示。
- 切换与历史：练习中切换不暂停、不结束 take，也不改变 coverage 或 valid frame count；应用从已存绝对误差重算当前 session，并重置后重放最近 120 ms feedback 窗口。再次开启可逆恢复绝对评分。上次录唱只在 Practice 内按当前模式临时重算，不改写历史文件；Review 显示 session 的“专业/八度折叠”标识。专业模式开启时继续使用精确“偏高/偏低”措辞；关闭后使用独立反馈呈现层：≤25 cents 以“目标内”为主状态，25–50 cents 使用“接近目标”和微调动作，50–100 cents 使用方向性调整动作，超过 100 cents 才使用“高于/低于目标”。signed cents、方向冗余、评分等级、指标和持久化数据保持不变。
- 异常：无声、丢帧、时间倒退，以及 80 ms 内超过 6 个半音的跳变必须断线但保留端点；专业模式下视窗外检测值只显示顶部/底部 overflow，不得钳制成合法音高。
- 验收：同音、±25/50/100 cents、±1～3 八度与 ±600 边界有黄金测试；模式往返后 observations、take 边界和指标恢复一致；NOW、每个校准刻度的中心与 ±25/50 cents 厚度坐标误差小于 0.5 px，刻度间距有界且不得跨过参考无声段；轻松反馈在 ±5/25/50/100 cents 边界有双语黄金测试，Review 的轻松模式整体摘要在 ±25 cents 内不得使用“偏高/偏低”；switch 支持 Tab/Space、文字状态、forced-colors、150% 缩放和至少 44 px 点击区域。

## 原唱辅助

### FR-028 — 在纯伴奏中切换原唱辅助人声

- 优先级：Must（v0.2 M9）
- 前置条件：歌曲有通过完整性验证且等长、同采样率的 `instrumental.wav` 与 `vocals.wav`，用户已经进入 Practice。
- 行为：Practice 在“专业模式”右侧提供“原唱 开/关”原生 switch；每次进入页面默认关闭且不持久化。关闭时只输出伴奏，开启时在同一 master gain 前混合伴奏与原唱 stem。播放、暂停、seek、回到开头、loop 和 suspend/resume 必须让两条 stem 共享既有 `AudioContext` 时基。
- 隔离：切换只改变原唱 gain，不暂停或重启 transport，不创建新逻辑 segment、不结束 take、不清空反馈、不改变参考轨、麦克风输入、音高观察、专业模式、评分、指标、session 或 Review 数据。
- 异常：原唱媒体加载、播放或重同步失败时自动回到关闭状态，伴奏和评分继续可用；页面显示结构化安全错误、数据状态和“重试原唱”动作。伴奏或分析整体损坏继续使用既有 Practice 资产错误路径。
- 验收：默认关闭、暂停态选择、播放中快速往返、seek、回零、十次 loop、suspend/resume 和原唱失败均有确定测试；开关前后的 position、segment、take、observations、feedback、pitch mode、metrics 和保存 session 保持一致；switch 支持 Tab/Space、可见文字状态、forced-colors、150% 缩放和至少 44 px 点击区域。

## 导航收尾

### FR-029 — 提供上下文完整且受退出门禁保护的页面导航

- 优先级：Must（v0.2 M10）
- 前置条件：应用已进入 Library、Practice、Review 或 Settings；Practice 可能存在尚未保存的 session。
- 行为：应用使用可穷尽检查的类型化路由状态表达当前页面及其歌曲/session 上下文。Library 和 Settings 始终可见；已选择歌曲时显示 Practice；已选择 session 时显示 Review。从 Library 直接打开 Review 后必须可以练习整首或错误区间。品牌首页动作必须导航到 Library，而不是只移动页面焦点。
- 退出门禁：活动 Practice 中选择 Library、Review、Settings 或首页时，目标页面只记录为 pending destination，并复用现有 session 保存、空会话保留/丢弃/取消和保存失败恢复流程；成功保存、明确丢弃或取消后必须同时清除一次性退出请求，避免 Practice 重挂载时重复消费旧事件。成功保存或明确丢弃后才提交目标路由，取消时留在原 Practice。不得通过顶部导航、窗口关闭或 Review/Practice 捷径绕过该门禁。
- 异常：目标歌曲资产或 session 已删除、损坏或重新分析时保留当前安全页面，显示结构化可恢复错误并允许返回 Library；较早异步导航结果不得覆盖较新的用户意图。
- 验收：Library→Practice→Review、Library→Review→整首 Practice、Review→区间 Practice、Practice→Library/Review/Settings/首页的保存/空会话/取消/失败矩阵、离开后重新进入 Practice、直接 Review 后导航完整性和双击/乱序异步结果均有自动测试；旧退出事件不得造成闪屏、立即离页或无法进入；键盘顺序、`aria-current` 和 1024×720/150% 缩放可用。
