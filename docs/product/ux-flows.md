## 视觉呈现规则

全部流程使用 [CyberMuse Signal UI](ui-design-system.md)。行为和状态以本文及 FR/NFR 为准，Signal UI 只决定呈现方式：dark/light 双主题、一个主焦点、主任务与支持内容两级布局、留白优先、有限 signal red、克制动效和可访问的文字/形状冗余。状态变化和错误必须就地显示本地化的保存、加载或错误标签，不得使用会自动消失的 Toast。任何页面不得为追求风格而隐藏恢复动作、缩小 Pitch Lane、使用未审查/联网字体、使用 skeleton，或让颜色成为唯一状态编码。

## 信息架构

主导航由类型化路由状态统一驱动，包含 Library、Practice（仅在歌曲已打开时）、Review（仅在 session 已选择时）和 Settings；进入 Practice 后不隐藏其他已经具备上下文的导航项。Import 是从 Library 进入的任务流，不作为永久导航页。活动 Practice 选择任一其他导航或品牌首页时只登记 pending destination，继续执行相同的 session 保存、空会话决定和失败恢复；保存成功、明确丢弃或取消后原子清除一次性退出事件，Practice 重挂载不得重放旧事件。保存成功或明确丢弃后才离开，取消则留在 Practice，不能通过 Settings 或首页绕过保存决策。

全局状态：

- 长任务可最小化到 Library，但不能静默消失。
- 错误使用稳定错误码，并提供重试、打开设置、释放空间或查看诊断等明确动作。

## Flow 1 — 首次启动

1. 显示产品目的和本地优先说明。
2. 不在启动时请求麦克风，也不自动下载模型。
3. 空 Library 显示“导入歌曲”和“先测试麦克风”两个入口。
4. 用户进入 Import 时才说明模型需求；进入 Settings 的输入与输出分类时才说明麦克风用途。

成功状态：用户知道数据保存在本机并能选择下一步。失败状态：配置损坏时使用安全默认值并显示可清除设置的提示，不阻塞 Library。

## Flow 2 — 导入与分析

1. 用户从 Library 选择“导入歌曲”。
2. 文件选择器只突出 MP3/WAV/FLAC；取消后回到原状态。
3. Import 显示文件名、格式、时长和预估本地空间，用户确认复制。
4. 如果模型缺失，展示名称、用途、大小、来源、许可证和“下载/取消”。取消保留歌曲为 `model_required`。
5. 分析页按 `probe → normalize → separate → pitch → postprocess → write` 显示阶段和总进度。
6. 用户可以取消；界面先显示 `cancelling`，完成清理后转为 `cancelled`，保留重试。
7. 成功后显示“开始练习”；失败显示错误原因、数据状态、重试和诊断入口。

状态集合：`selecting`、`validating`、`copying`、`model_required`、`queued`、`running`、`cancelling`、`cancelled`、`failed`、`ready`。

## Flow 3 — Library

每首歌曲列表项显示标题（默认来自文件名，后续可编辑）、时长、导入时间、分析状态、最近练习和本地占用；默认用留白和分隔线组织，不采用等权卡片网格。

- `ready`：主操作“练习”。
- `running`：显示阶段、进度、取消。
- `failed`：显示错误摘要、重试、删除。
- `model_required`：显示下载模型。
- `damaged`：显示缺失资产和删除/重新分析，不尝试静默修复。
- 空状态：说明支持格式、本地处理和首次分析可能较慢。

删除是破坏性操作：确认对话框列出将删除的原曲副本、派生文件和会话；成功后提供短暂的界面撤销仅在文件尚未实际清除时可用，否则不宣称可恢复。

## Flow 4 — Settings

设置使用左侧分类导航和单一内容区，窄窗口改用顶部原生分类选择器。分类依次为输入与输出、模型管理、存储管理、诊断与报告、主题与动效、语言；普通进入默认打开输入与输出，错误恢复动作可直接打开对应分类。仅挂载当前分类，离开输入与输出时立即释放实时音频资源。

1. 页面先显示为什么需要麦克风及“请求权限”按钮。
2. 授权后列出输入设备、系统默认输出、实时电平和检测到的音高。
3. 用户选择设备后执行输入测试；设备静音、被占用或消失时显示恢复步骤。
4. 延迟校准解释将播放短促声音，建议使用耳机并把麦克风靠近耳机。
5. 有效测量显示 `latencyMs`、置信度和设备组合；失败不保存值，可重试或使用手动偏移。
6. 语言支持跟随 Windows、简体中文和 English，切换立即更新当前页面；主题和动效在独立分类设置。
7. 存储分类只统计应用管理的固定目录；歌曲和模型使用现有单项删除确认，诊断日志清除需再次确认，不提供批量一键删除。

权限拒绝不是致命错误：Library 和歌曲分析保持可用，Practice 可进入预览但“开始录唱”不可用。

## Flow 5 — Practice

进入条件：歌曲 `ready`，参考轨有效。页面结构：

- 顶部：歌曲与右上角“退出练习”；退出继续执行会话保存、空会话选择和失败恢复，不提供无确认的数据丢弃捷径。
- 主区域：固定 NOW（位于可视宽度约 20%）、音高纵轴、向左移动的参考/用户轨；时间映射与 NOW 位置使用同一比例，减少无用的过去区间并为即将到来的参考音高留出空间。
- 即时反馈：“?”图例入口位于“等待录唱/正在录唱”行最左侧；目标音、当前音、signed cents 与状态在同一紧凑行按需出现。专业模式使用准确/偏高/偏低；轻松模式在 ±25 cents 内优先显示“目标内”，随后依次使用“接近目标”、方向调整动作和“高于/低于目标”，但继续保留 signed cents 与方向冗余。Pitch Lane 不再为 cents、文字摘要或未检测提示保留独立大块区域；麦克风已开启时即使尚未收到稳定音高，也显示绿色圆点与“正在录唱”。
- 底部：播放/暂停与“回到开头”使用标准 44×44 px transport 图标，之后依次放置“开始录唱”、A-B Loop、练习数据、紧邻其右侧的“专业模式 开/关”switch，以及专业模式右侧的“原唱 开/关”switch；seek 与时间紧邻操作区，Loop 与数据默认收起为图标入口。每次进入 Practice 专业模式默认开启、原唱默认关闭，两者在页面外都不记忆。

交互规则：

- 播放伴奏不自动开启麦克风；选择“开始录唱”先打开应用内说明对话框，只有用户继续后才请求系统权限并使用已授权设备。常驻页面不显示麦克风用途说明。
- 暂停冻结 NOW 和 session 时间；重新播放开始新的连续 segment。
- seek 清空跨越位置的平滑窗口，避免旧帧污染。
- 无声或低置信度显示中性状态，不判 Miss。
- 反馈等级需要滞回和时间平滑；轨迹仍可显示原始有效观察的轻量平滑版本。
- 专业模式关闭后，有参考的检测音高按最近整数八度折叠，曲线、当前音名、cents、反馈等级与当前 session 全部指标即时一致重算；±600 cents 平局保留原方向。再次开启必须可逆恢复绝对评分。切换不暂停、不结束 take、不改变 coverage/valid frame count，并重放最近 120 ms feedback；无参考帧保持未评分且不折叠。
- 原唱开启时，在同一播放时钟上把 `vocals.wav` 混入 `instrumental.wav`；关闭时只听伴奏。切换只使用 30 ms gain 过渡，不暂停、不 seek、不创建 segment、不结束 take，也不改变音高检测、反馈、专业模式、指标或已保存 session。原唱失败时自动关闭并提供“重试原唱”，伴奏与评分继续运行。
- Pitch Lane 的参考轨由约 80–120 ms 的独立实心校准刻度组成，刻度以嵌套厚度表达中心与 ±25/50 cents，不绘制连续外框、虚线边界或刻度间连接；乐句内纵轴固定，半音/C 网格提供音名定位。静音、丢帧、倒序和快速跨六个半音跳变断线；专业模式超出音域以顶/底 overflow 标记，不假装落在边界音上。
- 麦克风断开时伴奏暂停，提示选择新设备或以预览模式继续。
- A-B Loop 与练习数据使用互斥的内联展开区，一次最多打开一个。Pitch Lane 的可访问文字摘要保留在图形 accessible name 中，不作为视觉状态栏；三种线型由即时反馈行最左侧的“?”入口按需展开，默认不占布局空间。
- 进入同一分析版本的 Practice 时，“上次录唱”恢复最近已保存且含有效帧的 take；take 可以只覆盖歌曲的一部分。当前 session 的有效 take 完成后替代它，空预览段不替代；歌曲自然播放结束与暂停、seek、loop 边界一样显式结束当前 take。
- 上次录唱在 Practice 内按当前 switch 模式临时重算用于比较，但历史文件不改写；Review 使用 session summary 的“专业/八度折叠”标识解释已存指标。

## Flow 6 — A-B Loop

1. 用户在时间轴拖选或通过 A/B 按钮设置区间。
2. 合法区间必须在歌曲范围内且长度至少 1,000 ms。
3. 启用后，播放从 A 前 500 ms 预备位置开始；评分从 A 开始。
4. 到 B 时结束当前 take，短暂停顿 300 ms 后回到预备位置。
5. 页面显示 take 编号和最近三次指标；退出 loop 后保留区间但停止循环。

v0.1 不叠加无限条轨迹；只保存所有 take 数据，在 Practice 中最多显示参考、当前 take 和最近一次 take。

## Flow 7 — 结束与 Review

1. 用户选择右上角“退出练习”或关闭窗口。
2. 有有效观察时保存 session；无有效观察时在居中 modal 中询问丢弃还是保留空会话，不显示虚假分数。modal 将焦点置于明确决定并限制键盘焦点在对话框内；“继续练习”或 Esc 安全返回并丢弃尚未保存的旧快照，使后续录唱可重新 finalise。
3. Review 显示音准、median absolute error、signed median bias、稳定性、覆盖率。
4. 时间轴突出误差持续超过阈值的区间，摘要使用“整体偏低约 18 cents”等可解释语言。
5. 用户选择区间可“重新练习此处”，创建预填 A-B Loop 并返回 Practice。
6. 无论是否存在错误区间，Review 始终提供“练习整首”；从 Library 直接进入 Review 时同样建立当前歌曲上下文并显示 Practice 导航。

## Flow 8 — 用户提供的同步歌词

1. 用户在 Library 的歌曲行选择“添加歌词”或“替换歌词”；Rust 原生对话框只显示 `.lrc`。
2. 页面显示识别编码、标题/艺人 metadata、cue 数、第一/最后时间、最多三行预览和解析警告；取消不修改歌曲，确认后原子保存。
3. 已有歌词的歌曲行显示“歌词已添加”，并提供替换与经确认移除；歌词损坏显示“歌词需替换”，不改变歌曲 ready/分析状态。
4. Practice 有歌词时把原有 primary/controls 整体置于左列，右侧由 1 px 分割线划出歌词滚动区；没有歌词时保持原单列宽度。
5. 当前 cue 按播放位置高亮并滚动到中部；同刻多行作为一组显示。歌词列高度限制在 Practice 页头以下的剩余视口，少显示少量 cue 以使底部跟随状态或“回到当前行”无需滚动应用页面即可看到。内部滚动区不显示 scrollbar，但继续支持滚轮、触控和键盘滚动；用户手动滚动会暂停跟随，选择“回到当前行”恢复。
6. 点击歌词组或键盘 Enter/Space 通过既有 seek 语义跳转；不会更改 A-B loop。歌词标题栏的设置图标展开全局 offset，提供提前/延后 100 ms、数值输入与重置，保存失败回滚。
7. 窄窗口和 150% 缩放继续保留右侧歌词；歌词列优先保持可读宽度，Pitch Lane 和左侧控件允许收窄、堆叠或换行。

错误状态必须说明歌曲/已有歌词是否安全。歌词解析或读取错误不能阻止预览伴奏、录唱或保存 session；不得提供联网搜索作为恢复动作。

## 全局异常与恢复

| 场景 | 用户数据状态 | 必须提供的动作 |
|---|---|---|
| 麦克风权限拒绝 | 歌曲与分析安全 | 打开系统设置、重试、预览歌曲 |
| 分析器崩溃 | 已有有效缓存安全 | 重试、删除临时数据、导出诊断 |
| 模型下载失败 | 歌曲副本安全 | 重试、检查网络、取消 |
| 磁盘不足 | 旧数据安全，新写入未提交 | 打开存储管理、选择删除缓存、重试 |
| 资产被外部删除 | 其他歌曲安全 | 重新分析或删除损坏歌曲 |
| session 保存失败 | 当前内存数据暂存到离开前 | 重试、导出诊断、确认放弃 |

错误页面和对话框不得暴露 traceback、内部临时路径或无法执行的建议。
